## 🚀 Featured Projects

### 💎 [Madefor](https://shopmadefor.com) — Full-Stack Jewelry E-Commerce
Three-service architecture (storefront, admin panel, REST API) running at **$0/month** recurring cost. Paystack + Stripe with webhook-based payment confirmation, JWT auth with refresh-token rotation, and server-side cart validation to prevent overselling.
`React` `Node/Express` `Prisma` `PostgreSQL`

### 🗓️ [SchedulAI](https://github.com/Malottey1/schedulaiapp) — Hybrid Algorithmic & AI Timetabling
Greedy + genetic-algorithm scheduler that assigns **483 sessions across 20 rooms in under 30 seconds**. Five Dockerized services deployed via CI/CD on AWS EC2, monitored with Prometheus and Grafana. · [Demo](https://youtu.be/PbIbNjRH4WA)
`Python` `Flask` `MySQL` `Docker` `AWS EC2`

### 🛡️ [ArgosDefense](https://github.com/Kwasiyy/ArgosDefense) — Real-Time Fraud Detection
Flask microservice scoring transactions in real time with XGBoost — **98.65% accuracy, 0.9987 AUC**. SMOTE/ADASYN class balancing, containerized behind NGINX with health checks.
`Flask` `XGBoost` `NGINX` `Docker`

### 🏥 [Privacy-Preserving Federated Learning](https://github.com/Malottey1/privacy-fl-healthcare-)
Lets hospitals train a shared model without sharing raw patient data. Flower + PyTorch with differential privacy via Opacus, packaged as gRPC microservices. · [Demo](https://youtu.be/KHfhQsyjYg8)
`Flower` `PyTorch` `Opacus` `gRPC` `Docker`

### 🎭 [Emotion-Adaptive AI Interface](https://github.com/Malottey1/emotion-ui)
Browser-only facial-emotion detection that retunes a chat UI's color, motion, and tone in real time — no face data ever leaves the device.
`React` `TypeScript` `MediaPipe` `Gemini API` `MongoDB Atlas`
